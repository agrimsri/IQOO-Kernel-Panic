# Data sources for TraceVeil's own models

All sources are public. Raw files are **not** in Git (`ml/data/` is ignored); `python -P ml/fetch_data.py` downloads them again. Every licence below was read on its official page on **10 October 2026**, the download date of every file. SHA-256 values identify the exact files the committed metrics, plots and weights were produced from; a newer upstream file can give slightly different numbers, and the fetch script says so.

**CC BY 4.0 obligations we meet:** credit the creators (above, in `apk_permission_risk.json` → `trainingData`, and in the model card), link the licence, and say that we changed the data: we normalised permission names, merged one duplicated column, and dropped TUANDROMD columns that do not map to a single manifest permission name. The exported weights are a model trained on the data, not a copy of it.

**Data-quality facts we found (and handled):**
- NATICUSdroid: 21,964 of 29,332 rows (74.9%) repeat another row's exact permission vector; only 7,368 distinct vectors; 97 vectors appear with both labels. One malware profile alone repeats 1,171 times. Hence the group split by identical vector.
- NATICUSdroid has a column `android.permission.android.permission.READ_PHONE_STATE` (a doubled prefix some apps ship). It is merged into `android.permission.READ_PHONE_STATE` (logical OR), leaving 85 features. The Kotlin scorer applies the same rule.
- TUANDROMD: the published CSV replaced every `NO` inside column names with `goodware` (for example `BIND_goodwareTIFICATION_LISTENER_SERVICE`); we undo that. Only 474 distinct permission vectors among 4,464 rows. 163 columns map to full manifest names; 51 are dropped as non-platform or ambiguous (for example `RECEIVE`, `READ_SETTINGS`, `C2D_MESSAGE`, `ACTIVITY_RECOGNITION`). The exact list is in `ml/reports/apk_permission_risk/metrics.json`.

**Considered and not used:** DuckDuckGo Tracker Radar (CC BY-NC-SA 4.0, non-commercial only; it would restrict the whole model to non-commercial use, and EasyPrivacy was enough); Tranco and Cisco Umbrella top lists (we did not find a clear licence on their pages, so we used Majestic's explicit CC BY 3.0 instead).

**Known label limits:** the positives are the list editors' blocking decisions, not ground truth about data collection; popular sites in Majestic can still run tracking that the lists do not block (label noise in the negatives); lists change daily.
